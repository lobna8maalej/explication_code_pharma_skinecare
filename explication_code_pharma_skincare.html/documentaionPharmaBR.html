Bem-vindo à documentação do PharmaShop

Bem-vindo à documentação técnica do projeto PharmaShop, uma aplicação de comércio eletrônico desenvolvida com React, Node.js, Express e MongoDB.

Esta documentação apresenta a arquitetura do projeto, os modelos, os middlewares, a autenticação, as rotas, os controladores e os serviços.
